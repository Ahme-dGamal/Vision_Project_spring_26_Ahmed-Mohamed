# Food Classification with SHViT

## Setup

### Requirements
- Python 3.9
- PyTorch 1.11+
- Conda (local) or Google Colab (recommended)

### Local setup
```bash
bash "Stage 1: testing the SHViT model/setup_shvit.sh"
```

### Google Colab
Open `Stage 1: testing the SHViT model/SHViT_Food101_Colab.ipynb` in Colab.
Set the runtime to **T4 GPU**, then run all cells top to bottom.
